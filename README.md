## DESAFIO JAVANAUTA 

CRUD com PostgreSql

Especificações Técnicas:

1. Banco de Dados: Configure o PostgreSql para gerenciar duas entidades: Produtos
e Categorias.

3. Operações CRUD:

○ Produtos: Nome, descrição, preço, e ID da categoria.

○ Categorias: Nome.

Extras:

● Relacione produtos e categorias.
● Utilize Swagger para documentar os endpoints.

Estrutura de Rota Exemplo:

POST /api/produtos

GET /api/produtos/{id}

PUT /api/produtos/{id}

DELETE /api/produtos/{id}
